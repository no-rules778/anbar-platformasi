# Decision: Çap is not an acceptance requirement

Date: 2026-09-08

The product owner confirms that `Çap` has never worked anywhere in the platform. This is the accepted product baseline. A missing, disabled or non-working print action is therefore not a parity defect and must not block acceptance of any migration phase.

Existing historical implementation and test notes remain useful records of work already performed. They do not create a live print-preview gate. Excel and dedicated report exports remain independently in scope and retain their own verification requirements.
